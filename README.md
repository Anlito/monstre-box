# 🎃 Monstre Box

Application web pour smartphone (installable depuis Chrome) : un pad de 15 bruitages d'Halloween et un bouton « voix de monstre »
(un appui allume le micro, un deuxième l'éteint). Les sons sont fabriqués par la page (Web Audio),
aucun fichier son, rien n'est envoyé nulle part.

## Utilisation
1. Connecter l'enceinte Bluetooth au téléphone.
2. Ouvrir la page dans Chrome (Android) ou Safari (iPhone), à une adresse en `https`
   (le micro ne marche pas ailleurs).
3. Éloigner l'enceinte du téléphone pour éviter le sifflement (effet Larsen).

## Installer comme une application (Android, Chrome)
Ouvrir https://anlito.github.io/monstre-box/ dans Chrome, puis menu ⋮ → « Installer l'application »
(ou « Ajouter à l'écran d'accueil »). L'icône citrouille apparaît sur l'écran d'accueil ; l'appli
s'ouvre en plein écran et marche aussi sans réseau une fois ouverte une première fois.
